# 📝 Como criar sua conta no GitHub

> **Guia pra quem NUNCA usou GitHub.** É tipo criar conta no Instagram, mas pra desenvolvedores. Leva **3 minutinhos**.

---

## 🤔 Por que preciso de conta GitHub?

A Skill SMAM fica num "diretório protegido" no GitHub (parecido com Google Drive). Pra acessar ele, o GitHub precisa saber quem você é — daí a conta.

**Nada vai cobrar.** Conta GitHub gratuita resolve. Você não precisa entender de programação pra usar.

---

## 🪜 Passo a passo (3 minutos)

### **Passo 1 — Abra o site do GitHub**

No navegador (Chrome, Safari, Edge), abra:

```
github.com/signup
```

Vai aparecer uma tela com um campo perguntando seu email.

---

### **Passo 2 — Preencha seu email**

Use **o mesmo email** da Comunidade SMAM (pra gente confirmar mais fácil).

Clica em **"Continue"** (botão verde).

```
┌─────────────────────────────┐
│                             │
│      Sign up to GitHub      │
│                             │
│   Enter your email          │
│  ┌───────────────────────┐  │
│  │ seu@email.com         │  │ ← preenche aqui
│  └───────────────────────┘  │
│                             │
│  ┌──────────────────────┐   │
│  │     Continue         │   │ ← clica aqui
│  └──────────────────────┘   │
│                             │
└─────────────────────────────┘
```

---

### **Passo 3 — Crie uma senha forte**

Mínimo 15 caracteres OU 8 caracteres com 1 número e 1 letra minúscula.

**Dica:** use uma senha NOVA, não repita senha de outros sites.

Clica em **"Continue"**.

---

### **Passo 4 — Escolha seu username** ⚡ ATENÇÃO AQUI

Username é seu nome único no GitHub. Tipo @arroba do Instagram.

**Sugestões:**
- Use seu nome + sobrenome juntos (sem espaços), ex: `mariadasilva`
- Pode usar números, ex: `mariadasilva2026`
- Pode usar traços, ex: `maria-da-silva`

**❌ EVITE:**
- Espaços (não permitidos)
- Caracteres especiais como `@`, `#`, `&`
- Username muito longo ou difícil de digitar

> **🔑 GUARDE ESSE USERNAME.** Você vai mandar ele pra gente cadastrar você no diretório protegido.

Clica em **"Continue"**.

---

### **Passo 5 — Resolve o puzzle (humano ou robô?)**

GitHub vai pedir pra você resolver um pequeno puzzle visual (do tipo "selecione todas as pulseiras" ou clicar em alvos). É rápido, faz pra confirmar que você não é robô.

---

### **Passo 6 — Confirme o código no seu email**

GitHub vai mandar um **código de 8 dígitos** pro email que você cadastrou.

1. Abre o email (verifica spam também!)
2. Copia o código
3. Cola na tela do GitHub

---

### **Passo 7 — Pular as personalizações**

GitHub vai perguntar coisas tipo "quantas pessoas trabalham na sua empresa", "você quer notificações de quê" etc.

**Você pode pular tudo ou escolher qualquer opção.** Não faz diferença pro nosso uso.

No final, clica em **"Continue"** até chegar na tela inicial do GitHub.

---

### **Passo 8 — Tela inicial confirma que está tudo certo**

Você vai ver uma tela com seu nome de usuário no canto superior direito.

🎉 **Pronto! Sua conta GitHub está criada.**

## ❓ Dúvidas comuns

**P: Esqueci minha senha do GitHub. E agora?**
R: Em github.com/login, clica em "Forgot password?". Eles mandam link de redefinição no seu email.

**P: Posso usar um username diferente do meu nome?**
R: Sim! Pode ser apelido, nick, nome artístico. Só guarda direitinho pra mandar pra gente.

**P: O GitHub é seguro?**
R: Sim, é uma das maiores plataformas do mundo (de propriedade da Microsoft). 100+ milhões de usuários.

**P: Vou receber spam?**
R: Não. GitHub não vende seu email. Só você decide quais notificações receber.

**P: Preciso pagar alguma coisa no GitHub?**
R: NÃO. Tudo que você precisa fazer é gratuito.

**P: Posso desistir depois?**
R: Sim, pode deletar a conta a qualquer momento (Settings → Account → Delete).

**P: E se eu já tiver uma conta antiga?**
R: Pode usar a antiga. Só precisa lembrar o username e ter acesso ao email.
