Mini-tutorial GitHub
Pra quem nunca usou. Versão pra leigos, sem termos técnicos.
1
Abra o site: entre em github.com/signup no navegador (Chrome, Safari, Edge)
2
Email: coloque seu email (de preferência o mesmo da Comunidade SMAM) → clica "Continue"
3
Senha: crie uma senha forte (mín. 8 caracteres com 1 número) → "Continue"
4
Username: escolha um nome único (ex: mariadasilva2026). 🔑 ANOTE ESSE NOME — você vai mandar pra gente

Puzzle: resolve o teste visual (clique nos alvos pra confirmar que não é robô)
6
Código por email: abre seu email, copia o código de 8 dígitos, cola na tela do GitHub
7
Pular personalizações: pode pular as próximas telas (perguntas de empresa/uso). Não muda nada.
8
Pronto! sua conta GitHub está criada. Volte aqui pra continuar o cadastro ↓

Totalmente seguro (propriedade da Microsoft). Conta gratuita resolve, não vai cobrar nada. Não vendem seu email.

Porque a Skill fica num "diretório protegido" no GitHub. Pra acessar, o sistema precisa saber quem você é — daí a conta. É a forma técnica de impedir que pessoas não autorizadas baixem.
